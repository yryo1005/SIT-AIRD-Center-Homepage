# レポート 017

対象指示: `.orders/order_017.md`（チャットでの4点の指示：紹介ポスターPDF，活動サイクルのプロセス図，活動写真6点，AIコース詳細情報）

## 概要

アップロードされた紹介ポスターPDF・プロセス図の参考画像・活動写真6点・ガイダンス資料からの抜粋テキストを，それぞれ内容を確認したうえでサイトへ反映した。ポスターはダウンロードボタンとして，プロセス図はサイトデザインに合わせたHTML/CSSの図として，活動写真は在学生の方へページ・施設ページへ，AIコース情報は在学生の方へページの新設セクションへ配置した。

## 実施内容

### 1. 紹介ポスターのダウンロードボタン

- アップロードされた`AIRDCenter_ポスター.pdf`（A4・1ページ・約2.5MB）を`src/assets/documents/ai-rd-center-poster.pdf`として配置した。内容を確認したところ，既存サイトの記述（活動内容・研究業績・その他の活動・部屋の設備）と一致しており，矛盾する情報はなかった。
- `<a href="/src/assets/documents/...">`という直接指定では，`<a href>`属性がViteの標準アセット解析（画像の`<img src>`等とは異なる）の対象に含まれないため，ビルド後にファイルが見つからない問題が起きる。これは既存のJSON参照画像（`resolveImagePath()`）と同種の制約であるため，同じパターンで解決した：`src/shared/script.js`に`documentAssets = import.meta.glob("../assets/documents/**/*", { eager: true, import: "default" })`・`resolveDocumentPath()`・`wireDownloadLinks()`を新設し，HTML側は`<a data-download="ai-rd-center-poster.pdf" href="#" ...>`という仮のhrefを置き，`DOMContentLoaded`時に実際のビルド後URLへ書き換える方式とした。
- トップページ・在学生の方へページ・高校生の方へページのヒーロー部に，このボタンを配置した。

### 2. 活動のサイクルのプロセス図

- アップロードされたスクリーンショット（ガイダンス資料スライド「AIセンターでの過ごし方」）を確認し，「個人作業 →（毎週）→ ゼミ（木） →（毎月）→ 進捗報告（火） →（毎学期）→ ポスター発表（学期末）」という4段階のプロセスと，各段階への「教員・先輩からのフィードバック」ループを読み取った。
- 画像をそのまま貼り付けるのではなく，「これを参考に図を作成」という指示のとおり，サイトのデザイン（白背景＋青アクセント）に合わせたHTML/CSSベースの図として再構成した。`src/shared/style.css`に`.process-flow`／`.process-step`／`.process-arrow`／`.process-feedback`を新設し，各ステップの見出し・補足（画像内の箇条書きの要約）・矢印と頻度ラベル（毎週／毎月／毎学期）・フィードバックの注記を表現した。レスポンシブ対応として，画面幅720px以下では縦積みレイアウトに切り替わる。
- 在学生の方へページの「活動のサイクル」セクションに，既存の説明文の下に配置した。

### 4. AIコース詳細情報の追加

- ガイダンス資料からの抜粋テキストを，在学生の方へページに新設した「AIコースについて」セクション（アコーディオン形式）へ，原文の意味を変えずに転記した。項目は「AIコースの概要」「AIコースの実施体系」「プログラムを履修するための条件」「プログラム参加者に求められること」「メリット」「求める人物像・求めない人物像」「まとめ」の7項目。
- Python学習教材（Paizaラーニング「新・Python入門編」，`https://paiza.jp/works/python/new-primer`）へのリンクも，同セクション内に追加した。
- 既存の「参加方法」セクションは，これまで「具体的な参加の申込方法や手続きについては，本サイトでは断定的な案内をしておりません」という記述のみだったが，今回判明した確定事項（情報学部・工学部それぞれの必須履修科目）を追記した。指導教員への相談を促す記述自体は維持した（申込みの時期・具体的な手続き等，まだ判明していない事項があるため）。
- **転記時の注意点**：ユーザー提供のテキストの中に，授業時間についての表記ゆれが見られた（冒頭の箇条書きでは「木曜2〜4限，火曜5限」，実施体系の項では「木2〜5」）。これはユーザー提供資料内の情報であり，こちらで判断して一方に統一することはせず，それぞれの原文の文脈のまま，各項目の中で別々に転記した（「概要」の項は前者，「実施体系」の項は後者のまま）。もしこれが誤記であれば，正しい情報をご教示いただきたい。
