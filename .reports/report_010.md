# レポート 010

対象指示: `.orders/order_010.md`（チャットでの7点フィードバック）

## 概要

業績一覧アコーディオンの初期展開，強化学習ページの削除，公式サイト相当までのニュース情報量の拡充，ニューストップページの重複表示解消，指導教員写真の拡大，全体フォントサイズの再拡大とレイアウト見直し，そしてニュースデータの1件1ファイル化＋ポップアップ／カルーセル表示を実施した。既存の公式サイト由来データ（実績42件・教員情報等）は変更していない。

## 実施内容

### 1. 業績一覧を開きっぱなしに

- 基礎研究ページの「業績一覧（全42件）」の3つのアコーディオン（学術論文誌／査読あり国際会議プロシーディング／査読無し国内学会プロシーディング）を，すべて`aria-expanded="true"`・`.is-open`の初期状態に変更。クリックでの開閉自体は従来どおり可能。

### 2. 強化学習の項目を削除

- `site.config.js`の`PAGES`から`reinforcement`エントリを削除（`vite.config.js`・`INTERNAL_LINKS`・cms-shells生成はすべて`PAGES`から導出されるため，連動して除外される）。
- `src/pages/reinforcement/`ディレクトリと`cms-shells/reinforcement.html`を削除。
- 全ページのヘッダーナビゲーションから「強化学習」リンクを削除。トップページの「活動内容」カード一覧からも強化学習カードを削除。
- トップページのヒーロー説明文・meta description・「参加案内」の説明文中の「強化学習」への言及も削除し，「基礎研究・組込AI・画像処理・NLPの4分野」という表記に統一。
- README.md・開発用`index.html`内の強化学習への参照も削除。

### 3. ニュースの情報量を公式ページ相当に拡充

- `https://www.shonan-it.ac.jp/faculties/research-center/ai_rd_center/news/`を参照し，全21件のニュースについて，発表者名・発表タイトル・学会名を明記する形に本文を書き直した（複数件の発表がある場合は箇条書きで列挙）。
- 同ページに掲載されている画像も，件数・URLを直接確認したうえで不足分（13点）を追加でダウンロードし，1件のニュースにつき公式ページと同じ枚数の画像を持たせた（例：「電子情報通信学会総合大会2024」は4枚，「産学交流フォーラム」は3枚等）。

### 4. トップページの重複ニューススライダーを解消

- トップページに存在した文字のみの「ニュースティッカー」（`.news-ticker`）を削除し，写真スライダー（`.news-photo-slider`）のみを残した。
- `src/shared/script.js`から`renderNewsTicker()`・`initNewsTicker()`を削除し，関連CSS（`.news-ticker`系一式）も削除した。

### 5. 指導教員の写真を拡大

- `.faculty-photo`を60px角から104px角に拡大。
- レイアウトを縦積み（写真→テキスト）から，写真とテキストを横並びにするFlexレイアウトに変更し，写真が大きくなっても窮屈にならないようにした（560px以下の狭い画面では縦積みに戻す）。
- `.faculty-grid`の折り返しブレークポイントを760px/460pxから900px/560pxに変更し，カードが大きくなったことに合わせて早めに列数を減らすよう調整。
- 教員名・役職・キーワード・リンクのフォントサイズもあわせて拡大（例：氏名19px→23px）。

### 6. 全体のフォントサイズ拡大とレイアウト見直し

- `body`の基準フォントサイズを18px→19pxに拡大。
- 見出し・リード文・カード本文・統計数値・ニュース一覧など，主要なテキスト要素のフォントサイズを1〜4px程度引き上げた（例：`.card h3`21→23px，`.stat-number`34→38px，`.news-row h3`18→20px）。
- 指導教員カードのレイアウトを見直した点は上記5.のとおり。

### 7. ニュースデータの1件1ファイル化とポップアップ／カルーセル表示

- `src/data/news.json`（1ファイルに21件まとめる方式）を廃止し，`src/data/news/`フォルダの下に**ニュース1件＝1つのJSONファイル**（`{ date, title, body, images }`の4項目のみ）を配置する方式に変更した。
- `src/shared/script.js`で`import.meta.glob("../data/news/*.json", { eager: true })`を用いて全ファイルを静的インポートし，日付降順に並べ替えて描画する処理に書き換えた。
- ニュース一覧（`.news-row`）を`<button>`要素にし，クリックするとポップアップ（`.news-modal-overlay`）で日付・タイトル・本文全文・画像を表示するようにした。背景クリック・×ボタン・Escキーで閉じられる。
- 画像が複数ある場合は，ポップアップ内に前へ／次への矢印ボタンとページ番号（例：`2 / 4`）を持つ画像カルーセルを表示する。矢印キー（←→）でも送れる。
- README.mdの「ニュースを追加・編集する方法」を，新しいファイル構成・スキーマに合わせて全面的に書き直した。

## 検証

- `npm run build`成功（`reinforcement`ページはビルド対象から自然に除外されることを確認）。
- `npm run verify:cms-shells`：全ページ（7ページ）整合性OK。
- Playwrightによる全7ページの自動チェック：画像破損0件，コンソールエラー0件。
- Playwrightで実際にニュース一覧の行をクリックし，ポップアップが開いて画像カルーセルが「1 / 4」→「2 / 4」と正しく切り替わること，閉じるボタンでポップアップが閉じることを確認済み（`/tmp/modal_open.png`等）。
- スクリーンショットによる目視確認：業績一覧が開いた状態で表示されること，強化学習がナビ・カード一覧から消えていること，トップページのニューススライダーが写真のみの1本になっていること，指導教員写真の拡大とレイアウト，全体的な文字サイズの拡大を確認した。
