# report_001：AI R&D Center Webサイト再構築プロジェクト 実施レポート

対応する指示書：`.orders/order_001.md`

## 1. 実施内容の概要

湘南工科大学 情報学部 AI R&D Centerの紹介ページを，ArtisCMS3の「埋め込みHTML」機能に貼り付けて公開するための，静的HTML/CSS/JSソースを作成した．公式サイトの以下8ページを参照元として情報を取得し，内容を欠落・改変させることなく，ダークテーマ（黒背景・青ハイライト）の統合デザインへ再構成した．

- トップページ
- ニュース一覧
- 施設紹介
- 基礎研究（業績一覧を含む）
- 組込AI
- 画像処理
- NLP
- 強化学習

## 2. 情報取得の結果

各参照元ページから取得した主な情報は次のとおりである．

- トップページ：センターの概要文，指導教員6名（氏名・職位・個別プロフィールURL），活動内容4分野の紹介文，画像URL．
- ニュース一覧：2023年3月10日〜2026年6月16日の学会発表・受賞記録，全21件．
- 施設紹介：大会議室・小会議室・展示室・ヨギボーゾーンの4施設，各施設の説明文と画像URL．
- 基礎研究：学生インタビュー4件（発表者名・学年・研究概要・本人コメント・研究履歴），業績一覧42件（学術論文誌1件，査読あり国際会議1件，査読無し国内学会40件）．
- 組込AI・画像処理・NLP：研究テーマの紹介文のみが公式サイトに掲載されており，個別の発表者名・学会名・年度の記載は存在しなかったため，それらを捏造せず，公式サイトに記載された範囲の内容のみで構成した．
- 強化学習：公式サイト側にも本文コンテンツが存在しないことを確認し，指示書の方針どおり「準備中」ページとして構成した．

取得内容は実装着手前にチャット欄で一度提示し，ユーザーから「このまま実装に進める」との回答を得たうえで着手した．

## 3. 作成したプログラム・ファイル

指示書で指定されたフォルダ構成にもとづき，以下を作成した．

```
project/
├── shared/
│   ├── style.css     全ページ共通スタイル（ダークテーマ・青アクセント）
│   └── script.js     ナビ開閉・スクロール進捗バー・ニュースティッカー・タブ・アコーディオンの制御
├── pages/
│   ├── top/index.html
│   ├── news/index.html
│   ├── facility/index.html
│   ├── basic-research/index.html
│   ├── embedded/index.html
│   ├── image/index.html
│   ├── nlp/index.html
│   └── reinforcement/index.html
├── build.js          Node.js標準機能のみで動作するビルドスクリプト
├── package.json
├── README.md
└── dist/              build.js実行後に生成される出力先（8ファイル）
```

デザインは，指示書のトーン（見出しにセリフ体，本文にサンセリフ体，日付・数値にモノスペース体）を踏襲しつつ，ユーザーからの追加指示に従い，背景を黒，ハイライトを青とした．外部CDNへの依存をなくすため，Webフォントは読み込まず，各役割に近い書体をシステムフォントのフォールバックスタックで代替した．

各`pages/*/index.html`は，ArtisCMS3の「埋め込みHTML」欄にそのまま貼り付けられるよう，`<html>`/`<head>`/`<body>`を持たないHTMLフラグメントとして作成した．

## 4. build.jsの動作確認

Node.js（標準機能のみ使用，npm install不要）で`node build.js`を実行し，`pages/*/index.html`内の`<link rel="stylesheet" href="...">`と`<script src="...">`が，対応するファイルの中身で`<style>`・`<script>`タグへインライン展開され，`dist/`配下に8つの単一HTMLファイルとして出力されることを確認した．

```
出力しました: dist/basic-research.html
出力しました: dist/embedded.html
出力しました: dist/facility.html
出力しました: dist/image.html
出力しました: dist/news.html
出力しました: dist/nlp.html
出力しました: dist/reinforcement.html
出力しました: dist/top.html

合計 8 ページをdist/へ出力しました。
```

`dist/`配下の各ファイルに，展開されずに残った`<link rel="stylesheet">`や`<script src="...">`が存在しないことをgrepで確認済みである．また，全`<img>`タグにalt属性が設定されていることも確認した．

なお，実行環境に`node`コマンドが存在しなかったため，Node.js v20.17.0のバイナリをユーザー権限でダウンロード・展開し，一時的にPATHへ追加して動作確認した（システムへの恒久的なインストールは行っていない）．

## 5. 表示確認

`dist/`をローカルHTTPサーバー（UTF-8のContent-Typeを明示）で配信し，Playwright（Chromium）を用いてスクリーンショットを取得し，以下を確認した．

- トップページ：ヒーロー・実績サマリー（42件等の統計）・指導教員一覧・施設カード・活動内容カード・参加案内・お問い合わせパネルが，黒背景＋青ハイライトのデザインで崩れなく表示されること．
- 基礎研究ページ：学生の声4件のカード，業績一覧のアコーディオンが正しく表示され，クリックにより「査読無し国内学会プロシーディング（40件）」の区分が展開し，全40件が表示されること．
- モバイル幅（390px）でのレイアウト崩れがないこと，ハンバーガーメニューのクリックでナビゲーションが開閉すること．
- 公式サイトの画像URL（絶対パス）がすべて正常に読み込まれること．

初回のスクリーンショットでは，簡易サーバーがUTF-8のCharsetヘッダを送出していなかったために文字化けが発生したが，これはローカル確認環境側の設定不備であり，`dist/`ファイル自体はUTF-8で正しく保存されていることを`file`コマンドで確認済みである．Content-Typeを明示したサーバーで再確認したところ，日本語表示は正常であった．

## 6. 未解決の論点・次に検討すべき作業

- 組込AI・画像処理・NLPの各研究テーマについて，公式サイト側に発表者名・学会名・年度の記載がないため，本サイトでもその旨を明記するにとどめている．今後，公式サイトの情報が更新された場合は追従が必要である．
- 指導教員6名の個別プロフィールページ（裏取り用）は今回未取得である．氏名・職位はトップページの一次情報にもとづいており，現時点で矛盾は確認していないが，深掘りが必要であれば次フェーズで取得できる．
- 次フェーズ（指示書スコープ外）として，PDF/PPTXなどアップロード資料からの情報・画像抽出，GitHubリポジトリ化とGitHub Releaseを用いた画像の外部ホスティング，CSS/JSを外部CDN（jsDelivr等）から読み込む方式への切り替えが残っている．
- README.mdの「ArtisCMS3側ページURLとの対応表」は，指示書のとおり空欄のままとしており，運用者による手動記入が必要である．

## 7. ローカルからのアクセス方法

`dist/`配下のファイルは`<html>`/`<head>`を含まないHTMLフラグメントであるため，ブラウザで直接ファイルを開くのではなく，簡易HTTPサーバーで配信して確認する．

```bash
cd dist
python3 -m http.server 8000
```

起動後，ブラウザで`http://localhost:8000/top.html`（他のページは`news.html`，`facility.html`，`basic-research.html`，`embedded.html`，`image.html`，`nlp.html`，`reinforcement.html`）にアクセスすることで確認できる．文字化けを避けるため，Python標準の`http.server`ではなく，`Content-Type: text/html; charset=utf-8`を明示できる配信方法（詳細は`README.md`のNode.jsサンプルを参照）を用いることが望ましい．
