# report_005：デザイン刷新・内部リンクのモード切り替え 実施レポート

対応する指示書：`.orders/order_005.md`

## 1. 実施内容の概要

ユーザーが提示したHTML/CSSのデザイン参考例（白＋青のライトテーマ、Fraunces／Inter／IBM Plex Monoの組み合わせ、SVGネットワークアニメーション付きヒーロー、タブ切り替え式UI、円形写真のメンバーグリッド等）にもとづき、サイト全体の構造・デザインを刷新した。あわせて、「当面はGitHub Pages上で直接デバッグし、簡単にCMS前提に戻せるようにしてほしい」という指示に対応し、内部リンクの生成方式を切り替え可能にした。

指示書に添付されたデザイン参考例のHTMLは`.rtab-list{display:f`の途中で切れており、研究セクション以降のデザインが含まれていなかったため、実装着手前にユーザーへ適用範囲を確認した。「構造やデザインも変えてよい、技術的な実現方法は任せる」との回答を得たうえで、提示された部分のCSSパターンを全ページに適用し、未提示の部分（業績一覧・学生の声・参加案内・お問い合わせ・フッター等）は同じデザイン言語で一貫性を保つように独自に拡張した。

## 2. デザイン刷新の内容

### 2.1 配色・タイポグラフィ

`src/shared/style.css`を全面的に書き直し、ダークテーマ（黒背景＋ライム／パープルのアクセント）から、白背景＋青（`--accent:#1d4ed8`系）のライトテーマへ変更した。角丸は`--radius:2px`のシャープな矩形に統一した。各ページの`<head>`にGoogle Fonts（Fraunces・Inter・IBM Plex Mono）の`<link>`を追加した。

### 2.2 新設・変更したコンポーネント

- **ヒーロー**：CSSアニメーションで線を描画するSVGネットワーク装飾（`.hero-net`）をトップページに追加。`prefers-reduced-motion: reduce`環境ではアニメーションを無効化する。
- **指導教員セクション**：カード型から、3列グリッド＋円形グレースケール写真の「メンバーグリッド」（`.faculty-grid`）に変更した。
- **施設ページ**：4つの部屋を縦に並べる構成から、5つのスペース（入口・エントランス、大会議室、小会議室、展示室、ヨギボーゾーン）をタブ切り替えで閲覧する構成（`.tab-bar`＋`.tab-panel`）に変更した。
- カードグリッド・統計（stat-grid）・アコーディオン・学生の声（voice-card）・ニュース一覧（news-list）・お問い合わせ等、既存のコンポーネントは同一のクラス名を維持したままデザイントークンのみを更新し、HTML構造への影響を最小限にとどめた。

## 3. 内部リンクのモード切り替え（github-pages ⇔ cms）

サイト内の各ページを結ぶ`<a>`タグに`data-link="<key>"`（ページ内アンカーの場合は`data-hash="<hash>"`も）を付与し、実際の`href`・`target`属性は新設した`scripts/set-link-mode.js`が`site.config.js`の`resolveInternalLink()`にもとづいて機械的に算出する構成に変更した。

- `github-pages`モード：ページ同士の兄弟ディレクトリ構造を利用した`"../<key>/index.html"`という相対パス。`target`属性は付与しない。
- `cms`モード：`site.config.js`の`cmsPath`（大学ドメインの絶対パス）。`target="_top"`を付与する。

`node scripts/set-link-mode.js <mode>`を実行すると、`src/pages/*/index.html`（8ファイル）の該当箇所が一括で書き換わる。教員プロフィール・公式お問い合わせページ等の外部リンクは`data-link`を持たないため、どちらのモードでも書き換え対象外（常に`target="_top"`）である。

現在は`github-pages`モードを適用しており、GitHub Pages上のURLを直接開いてデバッグする運用にしている。

## 4. 動作確認

### 4.1 リンクモード切り替えスクリプトの検証

`node scripts/set-link-mode.js github-pages`を実行し、0ファイルが更新されること（＝手で書いたhrefがスクリプトの算出結果と完全に一致していること）を確認した。続けて`cms`モードへの切り替え（8ファイル更新、absolute path + target="_top"になることを確認）、再度`github-pages`モードへの切り戻し（8ファイル更新）を行い、双方向の変換が正しく動作することを確認した。最終的に`github-pages`モードの状態でコミットしている。

### 4.2 表示・機能確認

`npm run build`が問題なく完了することを確認した。`npm run preview`のローカルサーバー上でPlaywright（Chromium）を用いて以下を確認した。

- トップページ：ヒーローのSVGネットワークアニメーション、実績サマリー、メンバーグリッド（顔写真付き）、活動内容カード、参加案内が、白＋青のデザインで正しく表示されること
- ナビゲーションリンクのクリック：`../news/index.html`等の相対パスで正しく遷移すること（開発サーバー・プレビューサーバーの双方で確認）
- 施設ページのタブ切り替え：クリックでタブの見た目（選択状態）が切り替わることに加え、パネルの中身（写真・説明文）も正しく切り替わること
- モバイル幅（390px）でのレイアウト、ハンバーガーメニューの開閉
- 基礎研究・ニュース・組込AI・画像処理・NLP・強化学習の各ページの表示
- 全ページを通じてコンソールエラーが0件であること

### 4.3 実装時に発見・修正した不具合

施設ページのタブ切り替えUIを実装した際、`initTabs()`（`src/shared/script.js`、既存の関数）が`[data-tabs]`要素の子孫から`.tab-btn`と`.tab-panel`の両方を検索する実装になっているにもかかわらず、`data-tabs`属性をタブボタンの並び（`.tab-bar`）のみに付与し、`.tab-panel`をその外側に配置してしまっていたため、タブボタンの選択状態（ハイライト）は切り替わるが、パネルの中身が切り替わらない不具合が発生した。`data-tabs`属性をタブボタンとすべてのパネルを含む共通の親要素に付け直すことで解消し、修正後にPlaywrightで再検証して正しく動作することを確認した。

### 4.4 既知の軽微な表示上の課題（未修正）

組込AIページの「道路標識検出AIのためのUnityを用いたアノテーションデータ自動化」カードの画像（`yamazaki_unity.png`）は、横に並んだ2枚の比較画像が結合された横長の構図であるため、カード画像の`aspect-ratio: 16/10; object-fit: cover`によって画像内のテキストラベルの一部が見切れる。この画像自体の縦横比とCSSの組み合わせに起因する表示上の課題であり、今回のデザイン刷新以前から存在していたものである。指示書のスコープ外のため、今回は修正していない。
