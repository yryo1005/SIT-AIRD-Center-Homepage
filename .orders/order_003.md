# 追加指示：GitHub Pages公開URLの修正／画像表示の修正

対象リポジトリ：https://github.com/yryo1005/SIT-AIRD-Center-Homepage

## 背景

- GitHub Pagesは有効化済み。公開URLは `https://yryo1005.github.io/SIT-AIRD-Center-Homepage/`
- ここは「プロジェクトサイト」（ユーザー名.github.ioのリポジトリではない）のため、**すべてのURLにリポジトリ名`SIT-AIRD-Center-Homepage`がパスとして含まれる**仕様になっている
- 実際に確認したところ、トップページ（`https://yryo1005.github.io/SIT-AIRD-Center-Homepage/`）は表示できたが、`cms-shells`が参照しているニュースページのURL（リポジトリ名が抜けていた）は404になっていた。リポジトリ名を補って`https://yryo1005.github.io/SIT-AIRD-Center-Homepage/src/pages/news/index.html`にしたところ表示できた
- 併せて、公開されたページ上で画像が表示されていないことを確認した

## 指示1：URLの修正（リポジトリ名パスの補完）

`cms-shells/`配下の全ファイル（8ページ分）で、iframeの`src`属性に指定しているURLを確認し、すべて`https://yryo1005.github.io/SIT-AIRD-Center-Homepage/`を正しいベースパスとして含む形に修正すること。

- ベースパス（リポジトリ名）をファイルごとに個別にハードコードするのではなく、1箇所で管理できる形（設定ファイル・生成スクリプトなど）にし、そこから各`cms-shells/*.html`を生成・検証できるようにすることが望ましい
- `vite.config.js`の`base`設定、README.md内に記載されている公開URLの例、`cms-shells/`のURLの3箇所が食い違っていないか、必ず突き合わせて確認すること
- 修正後、8ページ**すべて**について、実際にブラウザで該当URLを開き、200で表示される（404にならない）ことを確認してから報告すること。1ページだけ確認して終わらせないこと

## 指示2：画像が表示されない問題の修正

現在公開されているページで、画像が表示されていないことを確認した。設計上、画像は公式サイト（`https://www.shonan-it.ac.jp/faculties/media/...`）の画像URLをそのまま`<img src="...">`で参照する方針になっている。以下の手順で原因を特定し、修正すること。

1. 各ページのHTMLソースに、想定通り`<img>`タグ・`src`属性が正しく実装されているか確認する（そもそも実装が漏れている可能性を先に潰す）
2. 実装されている場合、ブラウザの開発者ツールのNetworkタブ・Consoleで、画像リクエストが実際にどのようなステータスコード・エラー（403、404、CORSエラーなど）を返しているか確認する
3. もし403等で拒否されている場合、公式サイト側のホットリンク対策（Refererチェック）が疑われる。該当する`<img>`タグすべてに`referrerpolicy="no-referrer"`属性を追加し、別オリジン（GitHub Pages）から読み込む際にRefererヘッダーを送信しないようにしたうえで再検証する
4. それでも解決しない場合は、推測で対処を続けず、原因（URLの誤り・パスの取り違え・サーバー側仕様など）を特定した内容を報告すること。GitHub Releaseへの画像移設など、指示書でスコープ外としている対応を勝手に行わないこと

修正後、全8ページで実際に画像が表示されることを確認（可能であればスクリーンショット添付）してから報告すること。
