## 解釈・対応方針

1. **ポスターダウンロードボタン**：`AIRDCenter_ポスター.pdf`をリポジトリ内（`src/assets/documents/`等）に配置し，クリックでダウンロードできるボタンをトップページ（または適切な箇所）に追加する。`references/AIRDCenter_ポスター.pptx`も同名で存在するため，優先してPDF版を使用する。
2. **AIセンターでの過ごし方プロセス図**：スクリーンショット画像を確認し，内容（ステップ・矢印等）を読み取ったうえで，サイトのデザイン（白背景＋青アクセント）に合わせたCSS/HTMLベースの図として再構成する。画像をそのまま貼るのではなく「参考に図を作成」という指示のため，可能な限りHTML/CSSでの図表現を検討する（読み取れない・不確実な内容は含めない）。配置先は「活動のサイクル」セクション（joinページ）が最も自然。
3. **6枚の活動写真**：それぞれのファイルが何の写真か指定されているので，取り違えないよう1枚ずつ確認してから，「メンバー同士の交流」セクション（joinページ）に反映する。ヨギボーゾーンは施設ページとの関連もあるため，配置先を検討する。
4. **AIコース関連の事実情報**：ガイダンス資料からの抜粋テキストを，捏造・誇張せず，原文の意味を保ったまま，joinページの該当セクション（参加方法・FAQ等）に反映する。特に「履修条件」「メリット」「求める人物像／求めない人物像」「まとめ」は，参加を検討する学生にとって重要な確定事項であるため，正確に転記する。Python学習教材へのリンク（Paizaラーニング）も外部リンクとして追加する。既存の「参加方法」セクションで「本サイトでは断定的な案内をしておりません」としていた記述は，今回具体的な履修要件が明らかになったため，事実に基づいて更新する。
5. 各種確認後，実装→`npm run build`／`verify:cms-shells`→Playwright確認→`document.md`・`README.md`更新→`.reports/report_017.md`作成→コミット→`git push`（失敗想定）という通常フローに従う。
