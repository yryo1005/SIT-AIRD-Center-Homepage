# Order 011

## ユーザーからの指示（チャット，原文）

> 日本全国学会行脚マップを作成してください
> それぞれの都道府県をクリックするとそこでの写真がポップアップされるようにしてください
> この際画像をユーザーが都道府県ごとにアップロードできるようにしてください

## 解釈・対応方針

1. **日本全国学会行脚マップ** — 47都道府県を模した地図（簡略化した位置関係のドット地図）を新規ページとして作成する。これまでの学会発表（基礎研究ページの学会発表歴・ニュース）で訪れた都道府県を可視化する企画として位置づける。
2. **都道府県クリックで写真をポップアップ** — 地図上の各都道府県（マーカー）をクリックすると，その都道府県で撮影された写真をポップアップ（モーダル）で表示する。既存のニュース詳細ポップアップ（order_010で実装済み）と共通のモーダル／カルーセル基盤を再利用し，実装の重複を避ける。
3. **都道府県ごとに画像をアップロードできるようにする** — 本サイトはVite + GitHub Pagesの静的サイトであり，サーバー・バックエンドを持たない（order_002以降の一貫した方針）。そのため，ブラウザから直接アップロードして即座に公開する仕組み（保存先となるサーバーが必要）は持たせられない。かわりに，ニュース画像（order_009・010）と同じ「非技術者でもファイルを追加するだけで反映される」運用を踏襲する：
   - `src/assets/images/conference-map/<都道府県キー>/`フォルダに画像ファイルを追加するだけで，対応する都道府県のポップアップに自動反映される（`import.meta.glob`でフォルダ内の画像を自動検出するため，JSON等の追加記述は不要）。
   - 追加した画像は，通常のワークフロー同様`git push`でGitHub Pagesに公開される。
   - この運用方法をREADME.mdに追記する。
   - もしユーザーが本当にブラウザ上でのその場アップロード（フォームからの即時公開）を求めている場合は，バックエンドの追加が必要になるため，別途相談が必要である旨を作業完了時の報告に明記する。

## 実施上の注意

- 47都道府県の地図は，正確な行政区画のポリゴンではなく，簡略化した位置関係（模式図）のドットマップとする。
- 写真が未登録の都道府県もクリック可能とし，「まだ写真が登録されていません」という案内を表示する（一部の県だけ壊れて見えることを避けるため）。
- 現時点で明確に判明している開催地（例：ニュース内の「広島大学」ゲートの写真から広島県と判断できるもの）以外，学会の開催都道府県を推測・捏造しない。事実関係が不明なものは画像を割り当てない。
- 既存の公式サイト由来データ（実績42件等）は変更・削除しない。
- 実施内容は`.reports/report_011.md`に記録し，`document.md`に追記する。
