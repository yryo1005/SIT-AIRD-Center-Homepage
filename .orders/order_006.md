# 追加指示：表示内容の精査・修正（チャットでの指示）

ユーザーからチャットで以下の指示を受けた（原文のまま列挙）。

1. ニュースの画像をAIセンターのホームページから持ってくる
2. それぞれの数値のソースが何かを説明しなくて良い
3. 鎌塚先生と斎藤先生の写真が逆
4. 各ページの内容を精査する。基礎研究の部分にゼミや個人作業の様子があるがこれは不要なはず
5. AI特有の言い訳がましい文章は不要です
6. 画像が横長の時に見切れてる場合があるのでこれを修正する（いかなるサイズでも適切に表示する仕組みを導入）
7. 研究内容をガイダンス資料から抽出してそれぞれの分野の部分に盛って

## 指示の解釈・対応方針

1. 公式サイトのニュース一覧ページ（`https://www.shonan-it.ac.jp/faculties/research-center/ai_rd_center/news/`）を再取得し、各記事に紐づく画像（`<article>`内の`<img>`タグ）を記事ごとに対応付けたうえで、ニュース一覧ページの各行にサムネイル画像として追加する。
2. 実績サマリー・業績ハイライト・施設ページ・教員紹介等に付けていた「〇〇件は紹介ポスターに基づく」「顔写真はガイダンス資料に基づく」といった出典説明の脚注（`.stat-footnote`）をすべて削除する。
3. `src/assets/images/faculty/`内の鎌塚明・齋藤友彦の写真ファイルの中身を入れ替えて修正する（HTML側の参照は変更不要）。
4. 基礎研究ページの「取り組み中の研究例」セクション（ゼミ・ラウンジでの個人作業の写真を含む）を削除する。同セクションで紹介していた研究テーマ（圧力センサーAI、学内案内ChatBot）は、内容に応じて組込AI・NLPの各ページへ移設する。
5. 各研究分野ページ（組込AI・画像処理・NLP）にあった「公式サイト上には発表者名等が掲載されていません。実在しない情報を補うことは行わず…」という定型の免責文（notice-panel）、および強化学習ページの「公式サイトを確認しましたが…確認できませんでした」という経緯説明を削除・簡略化する。
6. `object-fit: cover`を使用していた`.card-img`・`.photo-strip img`・`.tab-photos img`を`object-fit: contain`＋背景色に変更し、画像の縦横比によらず全体が見切れず表示される仕組みに統一する。
7. `references/`のガイダンス資料（AIコースガイダンス_2026.pptx）から抽出した研究テーマのうち、未反映だったものを各分野ページに追加する（組込AI：圧力センサー姿勢判定AI、画像処理：Autoencoderによる有歪圧縮、NLP：学内案内ChatBot「AI英太郎」）。

対応内容の詳細は`.reports/report_006.md`を参照。
