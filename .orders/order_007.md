# 追加指示：コンテンツのデータファイル駆動化（第一弾：ニュース）

対象リポジトリ：https://github.com/yryo1005/SIT-AIRD-Center-Homepage

## 0. 背景・今後の全体方針（参考情報）

今後、以下の機能を順次追加していく予定である。

1. ニュースの簡単更新（今回対応）
2. 所属する学生の紹介・コラム（次回以降）
3. 過去の卒研生のテーマ・予稿一覧（次回以降）
4. 日本学会行脚マップ（都道府県タッチで画像表示）（次回以降）
5. ゼミ発表資料をGoogle Driveから取り込んで研究紹介を更新（半自動方式：Driveから自動取得するのではなく、発表資料を`references/`に置いたら、既存のガイダンス資料取り込みの仕組み（`.orders/order_004.md`）と同じ流れで反映する。Drive APIとの直接連携は行わない）

1〜3は「ページの中身をHTMLに直接書く」のではなく、「データファイル（JSON）を書き換えるだけで更新できる」形にすることで、実装の手間を共通化できる。今回はこの共通の仕組みを作り、まずニュースに適用する。学生紹介・卒研一覧へのデータ投入・ページ化は今回のスコープに含めない（次回以降指示する）。

## 1. 今回やること

### 1.1 データディレクトリの新設

`src/data/` ディレクトリを新設し、コンテンツをJSONファイルとして管理する構成にする。JSONを採用する理由は、追加のライブラリを入れずにVite（JavaScript）がそのまま`import`できるため。

### 1.2 ニュースのデータファイル化

- `src/data/news.json` を新設し、現在ページ内にハードコードされているニュース項目（日付・本文の配列）をここに移す
- ニュースを表示している箇所（トップページのティッカー、ニュースページの一覧など）のスクリプトを、この`news.json`を`import`して描画する形に変更する。表示用のHTML/CSSと、データの中身を分離すること
- 既存のニュース項目は1件も欠落・改変させないこと

### 1.3 更新手順のドキュメント化

`README.md`に、**HTMLやJavaScriptの知識が無い人でも迷わずニュースを追加できる手順**を、具体例つきで書くこと。最低限、以下を満たす説明にする。

- どのファイル（`src/data/news.json`）を開けばよいか
- 1件追加する際の具体的な書き方の例（コピペで使えるサンプルを1つ載せる）
- 保存後、コミット・pushすれば自動でGitHub Pagesに反映されること（既存のGitHub Actionsの仕組みで自動デプロイされる旨を明記）

## 2. 将来の拡張に備えた設計提案（今回は設計のみ、実装・データ投入は不要）

次回以降、学生紹介（`src/data/students.json`想定）・過去の卒研一覧（`src/data/theses.json`想定）も同じ仕組みで追加する予定である。今回のニュースの実装と一貫性が取れるデータ構造案（各JSONが持つべき項目案）を提案し、レポートに記載すること。実装・ページ作成は行わなくてよい。

## 3. 進め方

1. `news.json`のデータ構造案（フィールド名・型など）を先に提示し、確認を待つ
2. 確認後、実装する
3. `npm run build`が通ることを確認し、GitHub Pages上の該当ページURLで、ニュースが今まで通り正しく表示されることを確認する
4. README.mdの更新手順どおりに実際に1件テスト追加・削除してみて、手順に過不足がないか自己検証してから報告すること
